# Project Story Source Notes

The first four project profiles use Civil Solution Facebook imagery supplied by the client and confirmed by the client as public Civil Solution work authorized for website publication. The images are used without client names, addresses, identities, dates, private documents, or project-specific confidential details.

The authorized profiles describe only visible or client-approved work categories: total-station field surveying, constrained built-up site measurement, outdoor survey reference work, and construction observation around masonry and concrete elements. Their result language is limited to organized field information, technical notes, or documentation for the next decision; no measured outcomes, costs, performance claims, or client results are invented.

The fifth and sixth profiles are clearly labeled **Illustrative Service Profile**. They explain how Soil Test and Detailed Engineering Assessment services may be structured, using existing technical reference imagery rather than claiming a published client project.

The homepage confidentiality note states that project identities, technical documents, and site images are not published without permission. Authorized work profiles and illustrative service profiles are visibly distinguished by their tags.
